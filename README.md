# AmritaHub
AmritaHub is a web portal designed to provide easy access to essential information across all Amrita Vishwa Vidyapeetham campuses. It offers details on campus events, courses, clubs, and contacts, fostering connectivity and engagement among students, faculty, and staff.

## Features
1. **Campus Connectivity**: A seamless interface to explore all campuses and their offerings.
2. **Information Hub**: Access to important details about clubs, courses, events, and contacts.
3. **Engaging and Interactive**: Designed to foster student involvement and accessibility.
4. **Scalability**: Built to grow with Amrita, supporting future expansion.
